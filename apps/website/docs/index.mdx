# elysiax 文档

**elysiax** = Bun + Elysia 2 + htmx（服务端 TSX）+ React 逃生舱的全栈框架。
一棵页面目录树（`src/pages/`）内聚前端与后端，URL = 文件夹路径，
InferDI 容器 + codegen 把整棵树粘成类型安全的整体。
